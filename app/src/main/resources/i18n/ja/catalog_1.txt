= a scene button sets this to 1 to stop the scan within a quarter of a second; blank = only a progress panel's 中止 can stop it
: シーンのボタンがこの変数を1にすると、0.25秒以内にスキャンが止まります。空欄の場合は、進捗パネルの「中止」でしか止められません。
= Store report in
: レポートの格納先
= default Band_ScanReport — the full descriptive text, ready for a dialog
: 既定は Band_ScanReport — ダイアログにそのまま使える、説明付きの全文
= Store address in
: アドレスの格納先
= default Band_ScanAddress — the best MAC found, or blank if nothing was conclusive
: 既定は Band_ScanAddress — 見つかった最有力のMACアドレス。決定的なものがなければ空
= Store device count in
: デバイス数の格納先
= default Band_ScanCount
: 既定は Band_ScanCount
= Store verdict in
: 判定の格納先
= default Band_ScanVerdict — confirmed / likely / possible / none
: 既定は Band_ScanVerdict — confirmed / likely / possible / none
= Mark Training Session
: トレーニングセッションを記録
= Bookend a workout the band cannot see — strength work leaves almost no trace in a wrist sensor. Bind it to a shortcut or widget and tap at the start and end; 回復 then counts the session's real heart-rate load instead of missing it
: バンドが検知できないワークアウトの開始と終了を記録します。筋力トレーニングは、手首のセンサーにほとんど痕跡を残しません。ショートカットやウィジェットに割り当てて、開始時と終了時にタップしてください。そうすると「回復」は、そのセッションを見落とさず、実際の心拍負荷を計算に入れます。
= toggle (default) starts or ends whichever applies — the one to put on a button. pick opens the chart to draw a past session on. Or start / end / log
: toggle（既定）は、状況に応じて開始または終了します。ボタンに割り当てるならこれです。pick はグラフを開き、過去のセッションをその上に描き込めます。ほかに start / end / log
= Minutes (log only)
: 分数（log のみ）
= for mode=log: a session of this many minutes that ended just now, 5..240
: mode=log 用：たった今終わった、この分数のセッション。5..240
= optional, e.g. lifting — shown beside the session
: 任意。例：lifting — セッションの横に表示されます。
= Set OCR Models
: OCRモデルを設定
= Point 文字認識 at the directory holding its ONNX weight files. They are not in the APK — about 100 MB that never changes — so this is where that location is declared. Blank re-runs discovery over the usual directories
: 「文字認識」に、ONNXの重みファイルがあるディレクトリを指定します。重みファイルはAPKには含まれていません（約100 MBあり、内容は変わりません）。そのため、その場所をここで指定します。空欄にすると、通常のディレクトリを対象に探索をやり直します。
= Model directory
: モデルのディレクトリ
= blank = look in the usual places. e.g. /sdcard/〇/[227] 日本語/[227][66] 辞書/[227][66][362] 文字認識モデル
: 空欄の場合は通常の場所を探します。例：/sdcard/〇/[227] 日本語/[227][66] 辞書/[227][66][362] 文字認識モデル
= Recognise Text (OCR)
: 文字を認識（OCR）
= Read the text in an image entirely on-device (PP-OCRv5) into a variable. The same engine as the 文字認識 share tile — share a screenshot cut-out to that, or point this at a saved image
: 画像内の文字を、すべて端末上で（PP-OCRv5）読み取り、変数に入れます。共有タイルの「文字認識」と同じエンジンです。スクリーンショットの切り抜きをそこへ共有するか、このアクションで保存済みの画像を指定します。
= a file path, or a content:// / file:// URI. Leave blank with "Open the review window" on to open 文字認識 and pick an image there
: ファイルのパス、または content:// / file:// のURI。「確認ウィンドウを開く」をオンにして空欄のままにすると、「文字認識」が開き、そこで画像を選べます。
= blank = jpn (Japanese + English). Also: latin (German/Czech/Polish), eslav (Russian)
: 空欄の場合は jpn（日本語＋英語）。ほかに latin（ドイツ語/チェコ語/ポーランド語）、eslav（ロシア語）
= blank = %OCR. Also sets %<var>_lines and %<var>_script
: 空欄の場合は %OCR。%<var>_lines と %<var>_script も設定します。
= Model
: モデル
= blank = whatever the UI setting says. server = the accurate 81 MB model, mobile = the fast 16 MB one (Japanese/English only)
: 空欄の場合はUI設定に従います。server = 高精度の81 MBモデル、mobile = 高速な16 MBモデル（日本語/英語のみ）
= Open the review window
: 確認ウィンドウを開く
= true = show the image and text for checking instead of returning the text silently
: true にすると、文字列を黙って返す代わりに、確認用に画像と文字を表示します。
= Article to HTML (OCR)
: 記事をHTMLに（OCR）
= Read a scrolling screenshot into a formatted HTML file — headings, paragraphs, bold and italic, the photographs cropped out and inlined, every block sized against the body text. Handles pages far too tall for Recognise Text, and joins several screenshots of one article into a single file
: スクロールして撮ったスクリーンショットを、書式付きのHTMLファイルに読み取ります。見出し、段落、太字と斜体を再現し、写真は切り出して埋め込み、各ブロックの大きさは本文の文字を基準に決めます。「文字を認識」では扱えないほど縦に長いページも処理でき、1つの記事の複数のスクリーンショットを1つのファイルにまとめます。
= one path per line (or separated by |), in reading order. A repeated passage where two screenshots overlap is dropped automatically
: 1行に1つのパス（または | で区切る）を、読む順に並べます。2枚のスクリーンショットが重なる部分の繰り返しは、自動的に取り除かれます。
= Output directory
: 出力先のディレクトリ
= blank = /sdcard/tmp. The file is named <yyyy-MM-dd_HH-mm-ss>-<headline>.html
: 空欄の場合は /sdcard/tmp。ファイル名は <yyyy-MM-dd_HH-mm-ss>-<headline>.html になります。
= blank = the biggest type on the page. Also the filename
: 空欄の場合は、ページ内で最も大きい文字。ファイル名にも使われます。
= blank = mobile, the fast 16 MB model — an article is dozens of recognition passes, and the text is corrected by hand afterwards. server = the accurate 81 MB one. settings = follow the app-wide toggle
: 空欄の場合は mobile（高速な16 MBモデル）。1つの記事で認識を何十回も行ううえ、文字はあとで手作業で直すためです。server = 高精度の81 MBモデル。settings = アプリ全体の切り替えに従います。
