= Initial delay; exponential and capped at 10 seconds (100-5000)
: 最初の遅延。指数的に延び、上限は10秒です（100-5000）。
= MQTT Publish
: MQTTで発行
= Publish a bounded message to an MQTT 3.1.1 broker using the platform socket/TLS stack
: プラットフォームのソケット/TLSスタックを使い、上限付きのメッセージをMQTT 3.1.1ブローカーに発行します。
= Broker host
: ブローカーのホスト
= Hostname or IP address
: ホスト名またはIPアドレス
= Broker port
: ブローカーのポート
= Default: 8883 with TLS, 1883 without TLS
: 既定：TLSありは8883、TLSなしは1883
= Use TLS
: TLSを使う
= Topic
: トピック
= Publish topic, without + or # wildcards
: 発行先のトピック。ワイルドカードの + と # は使えません。
= Payload
: ペイロード
= Retain
: 保持（Retain）
= Ask the broker to retain the last message
: 最後のメッセージを保持するようブローカーに求めます。
= Username
: ユーザー名
= Optional broker username
: ブローカーのユーザー名（任意）
= Password
: パスワード
= Optional broker password; always redacted
: ブローカーのパスワード（任意）。必ず伏せられます。
= Connect, handshake, and acknowledgement timeout (1-30)
: 接続、ハンドシェイク、受信確認のタイムアウト（1-30）
= Run a bounded, retryable block and optionally handle its failure with Catch
: 回数に上限のある、再試行可能なブロックを実行します。失敗した場合はCatchで処理することもできます。
= Maximum attempts
: 最大試行回数
= Base backoff (ms)
: 再試行の基本間隔（ms）
= 0–60000; exponential between retries
: 0–60000。再試行のたびに指数的に延びます。
= Handle a failed Try block using FLOW_ERROR_* variables
: 失敗したTryブロックを、FLOW_ERROR_* 変数を使って処理します。
= Closes the matching Try/Catch block
: 対応するTry/Catchブロックを閉じます。
