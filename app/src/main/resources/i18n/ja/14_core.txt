# -- safety notes
= Creates a disabled profile. Review Do Not Disturb and volume access before enabling.
: 無効の状態でプロファイルを作成します。有効にする前に、おやすみモードと音量へのアクセスを確認してください。
= Creates a disabled profile and may need Do Not Disturb and volume access.
: 無効の状態でプロファイルを作成します。おやすみモードと音量へのアクセスが必要な場合があります。
= Creates a disabled profile and needs Write Settings access for brightness.
: 無効の状態でプロファイルを作成します。明るさを変えるには「システム設定の変更」の許可が必要です。
= Creates a disabled profile and may need nearby Wi-Fi or location permission.
: 無効の状態でプロファイルを作成します。付近のWi-Fiデバイスまたは位置情報の権限が必要な場合があります。
= Creates a disabled profile. Requires foreground/background location permissions and device Location before enabling.
: 無効の状態でプロファイルを作成します。有効にする前に、フォアグラウンドとバックグラウンドの位置情報の権限、および端末の位置情報を有効にしておく必要があります。
= Creates a disabled profile and requires Usage Access plus notification permission.
: 無効の状態でプロファイルを作成します。使用状況へのアクセスと通知の権限が必要です。
= Blocked until external trigger intents are exposed safely.
: 外部トリガーのインテントを安全に公開できるようになるまで、利用できません。
= Creates a disabled profile. Requires Calendar access plus Do Not Disturb and volume access before enabling.
: 無効の状態でプロファイルを作成します。有効にする前に、カレンダーへのアクセスと、おやすみモードおよび音量へのアクセスが必要です。
= Creates a disabled profile. Requires NFC hardware and Write Settings/volume access before enabling.
: 無効の状態でプロファイルを作成します。有効にする前に、NFC対応の端末と、「システム設定の変更」および音量へのアクセスが必要です。
= Creates a disabled profile. Needs Phone state, Call log, Contacts and notifications before enabling. The number leaves your phone only when you tap Search. Hidden callers and your contacts are never searched.
: 無効の状態でプロファイルを作成します。有効にする前に、電話の状態、通話履歴、連絡先、通知の権限が必要です。番号が端末の外に送られるのは「検索」をタップしたときだけです。非通知の着信と連絡先に登録された番号は検索しません。
= Creates a disabled profile. Needs Phone state, Call log, Contacts, notifications and Display over other apps before enabling. Every unknown caller's number goes to the search site without asking. Without Display over other apps Android won't open the browser, so the notification stays as the way to search by hand. Hidden callers and your contacts are never searched.
: 無効の状態でプロファイルを作成します。有効にする前に、電話の状態、通話履歴、連絡先、通知の権限と「他のアプリの上に重ねて表示」が必要です。知らない番号はすべて、確認なしで検索サイトに送られます。「他のアプリの上に重ねて表示」がないとAndroidはブラウザを開かないため、手動で検索できるよう通知が残ります。非通知の着信と連絡先に登録された番号は検索しません。
= Creates a disabled profile. Needs location access to read the Wi-Fi name, WireGuard tunnel control in Setup, and Allow remote control apps turned on in the WireGuard settings. It only changes the VPN as you join or leave that network.
: 無効の状態でプロファイルを作成します。Wi-Fi名を読み取るための位置情報へのアクセス、セットアップでのWireGuardトンネル制御の許可、WireGuardの設定で「Allow remote control apps」を有効にすることが必要です。VPNを切り替えるのは、そのネットワークに接続したときと離れたときだけです。
= Creates a disabled profile. Needs location access to read the Wi-Fi name, and you need to be logged in to Tailscale. It only changes the VPN as you join or leave that network.
: 無効の状態でプロファイルを作成します。Wi-Fi名を読み取るための位置情報へのアクセスと、Tailscaleへのログインが必要です。VPNを切り替えるのは、そのネットワークに接続したときと離れたときだけです。
= Creates a disabled profile. Before turning it on, open its action and pick the image with Browse, since RuleDeck can't read a typed photo path by itself. Sun times come from the latitude and longitude you enter, so no location access is needed.
: 無効の状態でプロファイルを作成します。RuleDeckは手入力した写真のパスをそのままでは読み取れないため、有効にする前にアクションを開き、「参照」で画像を選んでください。日の出と日の入りの時刻は入力した緯度と経度から求めるので、位置情報へのアクセスは不要です。
