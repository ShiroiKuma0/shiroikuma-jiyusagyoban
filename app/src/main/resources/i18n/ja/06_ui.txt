# docSections — "Concepts"
= Concepts
: 基本の考え方
= 白い熊 自由作業盤 automates your device. The pieces:
: 白い熊 自由作業盤は端末を自動化します。構成要素は次のとおりです。
= Project — an optional folder grouping profiles, tasks and scenes. Items with no project are "Unfiled".
: プロジェクト — プロファイル、タスク、シーンをまとめる任意の入れ物です。プロジェクトのない項目は「未分類」になります。
= Task — an ordered list of actions. Run on a trigger, a tile, a widget, or by hand.
: タスク — アクションを順番に並べたものです。トリガー、タイル、ウィジェットから、または手動で実行します。
= Action — one step in a task (show a notification, set a variable, send an intent, …).
: アクション — タスクの中の1ステップです（通知を表示する、変数を設定する、インテントを送る、…）。
= Profile — binds one or more contexts to an enter-task (and optional exit-task); active while all its contexts match.
: プロファイル — 1つ以上のコンテキストを開始タスク（と任意の終了タスク）に結び付けます。すべてのコンテキストが一致している間、成立します。
= Context — a condition: app in foreground, time window, day, location, device state, or a one-shot event.
: コンテキスト — 条件です。前面のアプリ、時間帯、曜日、位置情報、端末の状態、または一度きりのイベント。
= Scene — a floating overlay built from elements (text, button, slider, image …) that can run tasks on tap.
: シーン — 要素（文字、ボタン、スライダー、画像 …）で組み立てる、画面に浮かぶオーバーレイです。タップでタスクを実行できます。
= Widget template — a named home-screen widget layout, referenced by the Set Widget action and refreshed from variables.
: ウィジェットのテンプレート — 名前を付けたホーム画面ウィジェットのレイアウトです。「ウィジェットを設定」アクションから参照され、変数の値で更新されます。
= Variable — a named value (%name) read/written by actions; scope follows its case (see below).
: 変数 — アクションが読み書きする、名前の付いた値（%name）です。有効範囲は大文字・小文字で決まります（下記参照）。

# docSections — "Variables & scoping"
= Variables & scoping
: 変数と有効範囲
= Variables are written %name and their scope is decided by the case of the first letters:
: 変数は %name と書き、その有効範囲は先頭の文字の大文字・小文字で決まります。
= %ALLCAPS — super-global: one value shared everywhere (projectId 0).
: %ALLCAPS — スーパーグローバル：どこからでも共有される1つの値です（projectId 0）。
= %MixedCase — project-global: one value per project (the task's project; Unfiled maps to super-global).
: %MixedCase — プロジェクトグローバル：プロジェクトごとに1つの値です（タスクが属するプロジェクトのもの。未分類はスーパーグローバルになります）。
= %lowercase — task-local: ephemeral, lives only for that task run.
: %lowercase — タスクローカル：一時的なもので、そのタスクの実行中だけ存在します。
= Persisted variables (super-global and project-global) survive restarts and are listed on the Vars tab. Indexing like %array(2) is not supported — the parenthetical is literal text.
: 保存される変数（スーパーグローバルとプロジェクトグローバル）は再起動後も残り、「変数」タブに一覧表示されます。%array(2) のような添字指定には対応していません — かっこの部分はそのままの文字として扱われます。
