= When a run is refused
: 実行が拒否されたとき
= Log it
: 記録する
= A refused run leaves a skipped entry in the Run Log, saying which limit refused it.
: 拒否された実行は、どの上限で拒否されたかとともに、スキップとして実行ログに残ります。
= Drop it quietly
: 記録せずに破棄
= No Run Log entry. For a fast trigger whose refusals are noise rather than news.
: 実行ログには残しません。頻繁に発動するトリガーで、拒否の記録が邪魔になるだけの場合に向いています。
= Recovery task
: 復旧タスク
= Run when this profile's task fails and nothing in it caught the error. It receives the failure as variables — which task, which action, which message — so it can report or repair. It runs once and never triggers its own recovery.
: このプロファイルのタスクが失敗し、タスクの中でそのエラーが処理されなかったときに実行します。どのタスクの、どのアクションが、どんなメッセージで失敗したかを変数として受け取るため、報告や修復に使えます。実行は1回だけで、復旧タスク自身が失敗しても、もう一度復旧タスクが動くことはありません。
= None
: なし
= A failure is logged and left alone.
: 失敗は記録するだけで、何もしません。
