= Install Huawei watch face
: Huaweiウォッチの文字盤をインストール
= Push a captured watch face onto the watch. Faces are captured from Huawei Health's own upload — Health downloads them encrypted, decrypts, uploads and deletes, so the file that goes over the air exists nowhere on disk. This installs faces you already own, letting you rotate between them without re-pairing to the other phone; it cannot obtain new ones. The device verifies a SHA-256, so a truncated file is refused rather than installed broken
: 取り込み済みの文字盤をウォッチに送ります。文字盤はHuawei Health自身のアップロードから取り込んだものです。Healthは暗号化された状態でダウンロードし、復号してアップロードし、削除するため、無線で送られるファイルはディスク上のどこにも残りません。このアクションはすでに持っている文字盤をインストールするもので、もう一方の端末とペアリングし直さずに文字盤を入れ替えられます。新しい文字盤を入手することはできません。デバイスはSHA-256を検証するので、途中で切れたファイルは壊れたままインストールされず、拒否されます。

= Huawei watch workouts
: Huaweiウォッチのワークアウト
= Read the workouts the watch recorded — walks with their GPS tracks, and strength sessions, which have none. A workout is not part of the ordinary sync: it is an object the device numbered, with its own summary, its own heart rate stream (every five seconds on the Band 11 Pro) and the recovery curve it takes afterwards. Two things about a track file's decoding are unproven, so the raw bytes are always kept beside the GPX
: ウォッチが記録したワークアウトを読み取ります。GPSの軌跡付きのウォーキングと、軌跡のない筋力トレーニングです。ワークアウトは通常の同期には含まれません。デバイスが番号を振ったオブジェクトで、それぞれに概要、心拍数のストリーム（Band 11 Proでは5秒ごと）、終了後に測る回復曲線があります。軌跡ファイルの解読には未確認の点が2つあるため、生のバイト列を必ずGPXの横に残します。

= Which workouts

= Compare the two bands
: 2つのバンドを比較
= Put the HUAWEI Band 11 Pro and the Hume band side by side — one metric per card, both on one shared time axis and one shared scale. The two are never averaged together: the only figure derived from both is a signed difference, and a minute only one band recorded is counted as such rather than hidden
: HUAWEI Band 11 ProとHumeバンドを並べて表示します。1枚のカードに1つの指標を、共通の時間軸と共通の目盛りで示します。2つを平均することは決してありません。両方から導く数値は符号付きの差だけで、片方のバンドしか記録していない1分は、隠さずにそのとおり数えます。

= Probe Huawei watch
: Huaweiウォッチを調査
= Ask the watch what it actually supports and write the answer to a file — its service census, its command census, and which fitness count commands respond. Diagnostic: it reads and counts, and changes nothing on the watch. Run it again after a firmware update
: ウォッチが実際に何に対応しているかを問い合わせ、その答えをファイルに書き出します。サービスの全数調査、コマンドの全数調査、応答するフィットネス件数コマンドの一覧です。診断用：読み取って数えるだけで、ウォッチ上のものは何も変更しません。ファームウェア更新の後にもう一度実行してください。
= Write the report to
: レポートの書き込み先
= blank = /sdcard/tmp/huawei-probe_<millis>.txt. The path is also left in %HUAWEI_ProbeFile
: 空欄＝/sdcard/tmp/huawei-probe_<millis>.txt。パスは %HUAWEI_ProbeFile にも残ります。
= Store the path in
: パスの格納先
= a variable name to receive the report's path, or the reason it failed
: レポートのパス、または失敗の理由を受け取る変数名
= Full capability census
: 機能の全数調査
= default off. Asks the device about EVERY service id 0x01-0xFF, every command of each supported service and the expand bitmap — reads only, the same three questions Health asks on every connect — then stops. Saved per device and written beside the report as <out>_capabilities.json. For a new device (the Watch D3): the ordinary census only asks about the Band's 46 services
: 既定でオフ。0x01-0xFF のすべてのサービスID、対応する各サービスのすべてのコマンド、拡張ビットマップについてデバイスに問い合わせて終了します。読み取りのみで、Healthが接続のたびに尋ねるのと同じ3つの質問です。結果はデバイスごとに保存され、レポートの横に <out>_capabilities.json として書き出されます。新しいデバイス（Watch D3）向けです。通常の調査は、Bandの46サービスについてしか尋ねません。
= Also probe unknown commands
: 未知のコマンドも調査
= default off. Sends a count-shaped payload to fitness commands whose meaning is unknown — on the Band 11 Pro five of them ACCEPTED it and returned nothing, so this may set something on the watch. Only turn it on deliberately
: 既定でオフ。意味の分かっていないフィットネスコマンドに、件数問い合わせの形のペイロードを送ります。Band 11 Proではそのうち5つがこれを受理して何も返さなかったため、ウォッチ上の何かを設定してしまうおそれがあります。意図したときだけオンにしてください。
= Warm-up before listening
: 待ち受け前の準備送信
= diagnostic. Comma-separated from 0107,0105,0102,0103,0137,1a05 — or `all`. These are the six commands Huawei Health sends on EVERY reconnect and our routine session sends none of; the Band 11 Pro's first unsolicited frame arrived 104 ms after the last of them. None writes a setting, a clock or any wizard state
: 診断用。0107,0105,0102,0103,0137,1a05 からカンマ区切りで選ぶか、`all`。Huawei Healthが再接続のたびに送り、こちらの通常のセッションでは1つも送っていない6つのコマンドです。Band 11 Proが自発的に送る最初のフレームは、その最後のコマンドの104 ms後に届きました。どれも設定、時計、初期設定ウィザードの状態を書き換えません。
= Listen for unprompted frames (seconds)
: 自発的なフレームを待ち受け（秒）
= blank = off. Sends nothing and records everything the watch says on its own — the session already queues those frames and nothing has ever read them. A device wanting satellite assistance data asks its companion for it, and the request names the service that serves it. Entirely passive
: 空欄＝オフ。何も送らず、ウォッチが自分から発するものをすべて記録します。セッションはそうしたフレームをすでにキューに入れていますが、これまで誰も読んでいませんでした。衛星補助データを必要とするデバイスは連携相手にそれを要求し、その要求には提供するサービスの名前が含まれます。完全に受動的です。
= Also sweep the weather commands
: 天気コマンドも総当たりで調査
= default off. Knocks on 0x0F/0x02..0x09 with EMPTY payloads — the Band 11 Pro's census said it answered nine commands there and we use two. An empty payload is normally refused outright, which is the safest shape to probe with, but these are still unknown commands on the watch. Only turn it on deliberately
: 既定でオフ。0x0F/0x02..0x09 を空のペイロードで叩きます。Band 11 Proの調査結果では、そこで9つのコマンドに応答するとのことですが、こちらが使っているのは2つです。空のペイロードは通常そのまま拒否されるので、調べるには最も安全な形ですが、それでもウォッチにとっては未知のコマンドです。意図したときだけオンにしてください。
= Show Huawei Charts
: Huaweiのグラフを表示
= Open 健康（Huawei） in its own fullscreen window — the Huawei steps, heart rate, blood oxygen and resting heart rate (the HUAWEI Band 11 Pro until 2026-10-17, the HUAWEI WATCH D3 since), plus the coverage card that measures how much it actually recorded. Separate from the Hume band's 健康 window; the two data sets are never pooled
: 健康（Huawei）を専用の全画面ウィンドウで開きます。Huaweiの歩数、心拍数、血中酸素、安静時心拍数（2026-10-17まではHUAWEI Band 11 Pro、以降はHUAWEI WATCH D3）と、実際にどれだけ記録できたかを測るカバー率のカードを表示します。Humeバンドの健康ウィンドウとは別で、2つのデータを混ぜることは決してありません。
= Only this metric
: この指標のみ
= blank = the dashboard. One of: steps, hr, spo2, resting_hr
: 空欄＝ダッシュボード。次のいずれか：steps、hr、spo2、resting_hr
= Display language
: 表示言語
= en-US or ja-JP. Held separately from the Hume window's setting, so switching one does not switch the other. Blank keeps whatever was set last
: en-US または ja-JP。Humeのウィンドウの設定とは別に保持されるので、片方を切り替えてももう片方は変わりません。空欄の場合は前回の設定のままです。
= Huawei watch board
: Huaweiウォッチのボード
= Open 健康 -- [727], the one page the whole watch is driven from: sixteen cards — sync, the report, walks, satellites, weather, watch faces, the settings and the diagnostics — each a picture over a button, in the order the watch is actually used. Tapping a card runs its task and closes the board, so it never covers the window it just opened; sync alone opens a dialog here, with the full backfill and the sync state beside it
: 健康 -- [727] を開きます。ウォッチのすべてを操作する1枚のページで、16枚のカード（同期、レポート、ウォーキング、衛星、天気、文字盤、設定、診断）が並びます。どれもボタンの上に絵があり、ウォッチを実際に使う順に並んでいます。カードをタップするとそのタスクを実行してボードを閉じるので、開いたばかりのウィンドウを覆うことはありません。同期だけはここでダイアログを開き、完全な埋め戻しと同期の状態を並べて表示します。
= en-US or ja-JP. Shares the setting with 健康（Huawei）, and the board's own 日本語／英語 pill rewrites it in 健康の設定 rather than behind its back. Blank keeps whatever was set last
: en-US または ja-JP。健康（Huawei）と設定を共有し、ボード自身の「日本語／英語」ピルは、陰でこっそり変えるのではなく「健康の設定」の値を書き換えます。空欄の場合は前回の設定のままです。
= Pair Huawei watch
: Huaweiウォッチをペアリング
= Claim the Huawei watch for this phone — the Bluetooth pairing, the HiChain bind and the full configuration set in one run, because the Band 11 Pro gave a new companion only seconds before abandoning its flow. No Huawei account and no Huawei software. Two confirmations are needed: one on the watch (on the Band 11 Pro a plain yes/no, never a six-digit code), then Android's own dialog on the phone
: Huaweiウォッチをこの端末のものにします。Bluetoothのペアリング、HiChainのバインド、設定一式の送信を1回の実行で行います。Band 11 Proは、新しい連携相手に数秒しか与えずに手順を打ち切ったからです。Huaweiアカウントも、Huaweiのソフトウェアも不要です。確認が2回必要です。1回目はウォッチ上で（Band 11 Proでは単純な「はい/いいえ」で、6桁のコードではありません）、次に端末上でAndroid自身のダイアログに応えます。
= blank = the watch's known address. It is a PUBLIC address (on the Band 11 Pro it survived a factory reset), so there is nothing to scan for
: 空欄＝ウォッチの既知のアドレス。公開アドレスなので（Band 11 Proでは初期化後も変わりませんでした）、スキャンで探す必要はありません。
= Huawei account ID
: HuaweiアカウントID
= %Huawei_AccountId from 健康の設定. Private: stored only in the app's own settings, never exported. Blank keeps the stored one; with none stored the account steps are skipped
: 「健康の設定」の %Huawei_AccountId。非公開：アプリ自身の設定にのみ保存され、エクスポートされることはありません。空欄の場合は保存済みのものを使い、保存がなければアカウントのステップを省きます。
= Device name
: デバイス名
= e.g. HUAWEI Band 11 Pro-90F — the device expects to be told its own name during provisioning. Blank keeps whatever is stored
: 例：HUAWEI Band 11 Pro-90F。デバイスは初期設定の際に自分の名前を知らされることを前提としています。空欄の場合は保存済みのものを使います。
= Make it the active device
: 使用中のデバイスにする
= true = once paired, every Huawei task without its own address talks to this device. Default false, so pairing a second device (the Watch D3) leaves the Band syncing as before; each device keeps its own bind either way
: true＝ペアリングが済むと、アドレスを個別に指定していないすべてのHuaweiタスクがこのデバイスと通信します。既定は false で、2台目のデバイス（Watch D3）をペアリングしても、Bandはこれまでどおり同期を続けます。どちらの場合も、各デバイスは自分のバインドを保ちます。
= Time limit (seconds)
: 制限時間（秒）
= default 180, and it covers the two human confirmations — generous by design. Two more minutes are allowed on top for the pairing itself
: 既定は180。人が行う2回の確認を含むため、あえて長めにしてあります。ペアリングそのものには、さらに2分が上乗せで認められます。
= Stay connected after, at most (seconds)
: 完了後に接続を保つ最長時間（秒）
= default 45, and it is a CAP rather than a wait: the watch is answered until it goes quiet, which on the Band 11 Pro was usually 20-30 s. The Band kept asking questions after the configuration set — the first arrived about four seconds later — and a companion that hung up during that exchange was treated as no companion at all, so the Band dropped back to its out-of-box screen even though every command succeeded
: 既定は45。待ち時間ではなく上限です。ウォッチが静かになるまで応答を続け、Band 11 Proでは通常20-30 sでした。Bandは設定一式の後も問い合わせを続け（最初のものは約4秒後に届きました）、そのやり取りの途中で切断した連携相手は、連携相手がいないものとして扱われました。そのため、すべてのコマンドが成功していても、Bandは初期設定前の画面に戻ってしまいました。
= default HUAWEI_ — writes <prefix>Phase (live: pairing, connecting, handshake, device, configuring, serving), Ok, Summary, Bound, Address
: 既定は HUAWEI_。<prefix>Phase（実行中の値：pairing、connecting、handshake、device、configuring、serving）、Ok、Summary、Bound、Address を書き込みます。
= a variable name to receive the one-line result, success or failure
: 成功でも失敗でも、1行の結果を受け取る変数名
= Sync Huawei watch
: Huaweiウォッチを同期
= Pull the Huawei watch's stored history into its own tables, over Bluetooth Classic. Kept entirely separate from the Hume band's data — the two are compared side by side, never pooled. The watch must be paired first; the first sync also binds it, which needs no Huawei account
: Huaweiウォッチに保存された履歴を、Bluetooth Classic経由で専用のテーブルに取り込みます。Humeバンドのデータとは完全に分けて保持し、2つは並べて比較するだけで、混ぜることは決してありません。先にウォッチをペアリングしておく必要があります。最初の同期ではバインドも行いますが、Huaweiアカウントは不要です。
= blank or auto = continue from the last successful sync with the configured overlap. all = walk back as far as the cap allows, which is also how the watch's buffer depth gets measured. Or an epoch-seconds instant
: 空欄または auto＝最後に成功した同期から、設定した重なりを付けて続行します。all＝上限の許す限りさかのぼります。ウォッチのバッファの深さを測るのにもこれを使います。エポック秒の時刻も指定できます。
= blank = the address from 健康の設定. A PUBLIC address, so unlike the Hume band there is nothing to scan for
: 空欄＝「健康の設定」のアドレス。公開アドレスなので、Humeバンドと違ってスキャンで探す必要はありません。
= default HUAWEI_ — writes <prefix>Phase, Pct, Records, Inserted, Ok, Summary, SyncId, LastSuccess, AgeHours, BatteryPct, BatteryAgeHours, Firmware, ObservedDepthHours, MissingCount, SyncCount
: 既定は HUAWEI_。<prefix>Phase、Pct、Records、Inserted、Ok、Summary、SyncId、LastSuccess、AgeHours、BatteryPct、BatteryAgeHours、Firmware、ObservedDepthHours、MissingCount、SyncCount を書き込みます。
= blank = the value from 健康の設定 (180), coerced to 10..1800. Wider than the Hume band's range because this device is fetched record by record, so a busy day is simply more round trips
: 空欄＝「健康の設定」の値（180）。10..1800 の範囲に丸められます。Humeバンドより範囲が広いのは、このデバイスでは1レコードずつ取得するためで、記録の多い日はその分やり取りが増えるだけです。

= Initial span (minutes)

= Speed Test
: 速度テスト
= Measure download/upload throughput over a chosen transport. Pins its own network, so a mobile test runs with WiFi still connected — WiFi never has to be switched off

= Transport
: 通信経路
= cellular = the SIM carrying data; auto = current default route
: cellular＝データ通信に使っているSIM、auto＝現在の既定の経路
= Direction
: 方向
= default: both
: 既定：both
= Seconds per leg
: 片方向あたりの秒数
= default 10 — the CLOCK is the limiter, as in Ookla; the size cap is only a runaway guard
: 既定は10。Ooklaと同じく、測定を区切るのは時間です。サイズの上限は暴走防止にすぎません。
= Max MB per leg
: 片方向あたりの最大MB
= default 4000 — a runaway guard, not a target. Set it low only if you want to cap data; a cap that binds first ends the leg mid-ramp and under-reports
: 既定は4000。暴走防止のための上限で、目標値ではありません。データ量を抑えたいときだけ低く設定してください。上限に先に達すると、速度が上がりきる前にその方向の測定が終わり、実際より低い結果になります。
= Parallel streams
: 並列ストリーム数
